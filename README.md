# INPSYT Catalog Viewer

## 프로젝트 목적
- 2026 인싸이트 카탈로그 PDF를 WebP 이미지로 변환해 GitHub Pages에서 가볍게 열람할 수 있는 전자책 UI를 제공합니다.
- `pages.json`과 `quicklinks.json`을 이용해 페이지 메타데이터, 검색, 목차 이동 기능을 지원합니다.
- 향후 고객 맞춤형 소개나 배포용 링크로 활용할 수 있는 안정적인 싱글 페이지 뷰어를 만드는 것이 목표입니다.

## 현재 진행 상황
- PDF → WebP 변환 스크립트(`convert_pdf_to_webp.py`)와 `webp/` 자산이 준비되어 있습니다.
- `index.html`은 빠른 이동, 검색, 한면/두면 보기, 확대/축소, 썸네일 바 등 주요 UI를 갖춘 상태입니다.
- `pages.json`, `quicklinks.json`과 같은 데이터 파일을 로컬 서버(`python -m http.server`)를 통해 문제없이 로드할 수 있습니다.
- GitHub Pages 배포(예: `main` 브랜치)를 통해 실제 서비스 환경에서도 똑같은 UI를 재현할 수 있습니다.
